Retrieve a paginated list of all send requests created in your account. A send request represents a payout initiated from your balance to a specified beneficiary. This endpoint lets you audit, track, and manage payouts, including amounts, currencies, fees, and blockchain transactions.

> 📘 Send Request Object
>
> The Send Request response has the same structure as the Send Request Callback. For detailed descriptions of each field, please refer to the ‘[Send Request Callback](https://developer.coingate.com/reference/send-request-callback)’ documentation page.
