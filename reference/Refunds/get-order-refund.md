  Retrieves a specific refund for an order.


  Before making a <b>GET Order Refund</b> request, a [POST Create
  Order](/reference/create-order) request should be made. 


  After an order is created, you will get the order ID which will be used in the
  <b>GET Order Refund</b> request.


  Before making a <b>GET Order Refund</b> request, a [POST Create Order
  Refund](/reference/create-refund) request should be made.


  After creating a refund for an order, you will get the refund ID which will be
  used in the <b>GET Order Refund</b> request.
